# Robot Planar de 3 GDL – Velocidades Lineal y Angular

## Descripción
Este repositorio documenta el desarrollo del modelo cinemático y el análisis de velocidades
de un robot manipulador planar de tres grados de libertad (3 GDL).

Se parte de un modelo base de 2 GDL y se extiende a 3 GDL, obteniendo:

- Cinemática directa
- Jacobiano lineal
- Jacobiano angular
- Vector de velocidades del efector final

## Objetivo
Calcular simbólicamente la velocidad lineal y angular del efector final mediante el Jacobiano.

## Herramientas utilizadas
- MATLAB (Symbolic Math Toolbox)

## Contenido
- `/docs` → explicación teórica y reporte
- `/matlab` → código MATLAB
- `/docs/figuras` → diagramas e ilustraciones
